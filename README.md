# 雪王现代桌宠

这是一个独立的 Windows WPF 桌宠，形象融合了至冬女皇的银蓝色冰雪气质、雪王的圆滚外形与甜筒权杖，以及“咕咕嘎嘎”的幼崽互联网气质。它和菜狗桌宠的进程、素材和存档完全分开，可以同时运行。

当前版本：`0.9.0-rc.3`。这一版完成了“雪王陪伴屋”视觉重做、系统托盘、多屏防丢失、首次引导、偏好记忆、标准用户数据目录和干净发布包，并新增设置面板、开机自启、交互音效、时段感知台词和系统状态监控。它仍是**未获商业授权的非官方二创预览版**；收费上架前先看 `COMMERCIALIZATION.md`。

## 启动

- 双击 `启动动态雪王.vbs`，会静默启动，不弹 PowerShell 黑窗口。
- 也可运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\雪王现代桌宠.ps1`。
- 默认不创建桌面快捷方式、不启用开机自启；可在设置或托盘中手动开启自启。
- 启动后会常驻系统托盘；双击托盘图标可打开陪伴屋，右键可找回桌宠或安全退出。

## 怎么玩

- 点击头发中央：温柔摸头，可以消除一部分委屈。
- 身体现在分成 9 个真正独立的热区：王冠、左/右脸颊、左/右耳朵、肚皮、甜筒权杖、披风和小脚。悬停会出现很轻的冰晶触点提示。
- 同一部位连续点击会经历“轻微反应 → 明显抗议 → 部位专属小剧情”；普通单击不算欺负，快速连戳到第三次才会让心绪结霜。
- 左键按住约 0.85 秒会触发长按反应，例如脸颊压扁回弹、揉肚皮、披风裹团、权杖蓄力反噬和抱雪球滑行。
- 睡着时仍按部位区分：王冠弹飞、睡脸压痕、耳朵抖动、梦中护食、抱紧权杖、卷披风或梦中踢腿，不再全部使用同一种惊醒。
- 连续碰不同部位可触发组合剧情：王冠→权杖、权杖→披风、披风→小脚、投喂→肚皮、左右耳交替。
- 右键雪王可明确打开或关闭“雪王陪伴屋”。单纯悬停、普通点击和随行巡游中的停驻都不会自动弹出面板。
- 陪伴屋有四个页面：“近况”查看六项状态、快捷照顾和最近记录，“互动”提供九个身体触点与八种陪伴动作，“珍藏”用于五槽甜品珍藏与套装组合，“设置”调整陪伴模式、大小、自启、音效等偏好。
- 陪伴屋打开时，交互台词显示在面板内部的固定回执区域；关闭面板后，台词恢复为贴近雪王的轻量语言条。
- 操作卡支持鼠标、Tab、Enter 和空格；桌宠不会再被拖出当前显示器的可用工作区。
- 快速拖动会进入雪球滑行并摔成扁团；长时间拎着则会用披风抗议。普通快速双击仍属于身体互动。
- 跟随鼠标：用小企鹅步一直陪跑，停止后她会自己回到右下角。

## 自然作息

默认使用低打扰的块状作息，而不是每十几秒随机乱动：

- 睡眠阶段通常持续 18–45 分钟，夜间可达 45–120 分钟；梦中微动相隔 6–14 分钟。
- 安静清醒阶段持续 10–25 分钟，每 3–7 分钟换一次姿势。
- 短暂活跃阶段仅 2–4 分钟，每 28–65 秒可能表演一次企鹅步、晃权杖、巡逻或小跳。
- 主动求关注的普通窗口是 40–75 分钟；很饿或生命状态危险时才会更频繁地表达需求。

## 完整机制

- 52 组动作与表情、271 张 192×208 RGBA 透明帧，WPF 高质量缩放。
- 基础 12 组：待机、睡眠、等待、观察、挥手、摸头、进食、跳舞、跌倒、奔跑与左右移动。
- 情绪 8 组：馋嘴、被欺负、愤怒、得意、吃撑、害羞、晕乎、鼓腮。
- 身体反应 8 组：王冠、脸颊、耳朵、肚皮、权杖、披风、小脚和惊醒。
- 新增 24 组大轮廓剧情姿态：Doro 式四足偷吃、扑食护卫、披风裹团、噩梦藏身、摔成雪饼、肚皮扑倒、冰术施法与反噬、拆零食袋急哭、咬袋、掉冠追冠、雪球游戏与滑行、脸颊挤压回弹、盛宴护食、深夜偷吃和最后一口。
- 48 套清醒自主套路与 5 套睡眠套路；仍沿用长时间安静、短时间活跃的低打扰作息。
- 生命、饱食、体力、亲密、馋嘴、委屈六项状态、五个珍藏槽位、套装冷却和界面偏好保存在 `%LOCALAPPDATA%\SnowCourt\XueWangPet\state.json`；首次启动会复制旧版目录存档。写入继续使用临时文件原子替换并保留 `state.json.bak`。
- 馋嘴会独立增长，所以吃饱后仍可能盯着甜筒流口水；投喂会显著降低馋嘴，也能安抚委屈。
- 每个部位独立记录连点次数和冷却，不再由一个全局“生气”状态覆盖所有反应；停止欺负后委屈会自然消退。
- 包含长期忽视、过度摸头、长时间拖拽和连续欺负的边界反馈。
- 至冬面板使用极夜蓝、霜白、极光青、档案金与克制宫廷红的三层设计令牌；六项状态采用五段冰晶仪表和人格化描述，不再是六根通用进度条。
- 透明异形窗口、柔和阴影、冰晶粒子、反馈卡、跟随鼠标，以及“面板内回执／面板外语言条”互斥显示。
- 四页陪伴屋：近况、互动、珍藏、设置。设置页整合陪伴模式、桌宠大小、开机自启、交互音效、快捷操作和关于信息。
- 开机自启：托盘菜单或设置页一键开关，通过注册表 Run 键实现，登录后自动启动。
- 交互音效：根据互动语气播放轻量系统提示音（点击、投喂、开心、委屈、睡眠等），可随时开关。
- 时段感知：清晨、上午、午间、下午、傍晚、深夜各有专属问候台词；元旦、情人节、春节、中秋、国庆、圣诞等节日会触发专属祝福。
- 系统状态监控：高负载或内存紧张时，雪王会偶尔评论电脑状态，不打扰工作。

## 甜品珍藏

内部机制沿用五位置结构：永冻之花、赤羽之翎、柠光之刻、皇室御盏和初雪之冠。每个槽位有三个候选，共 15 件；可以组成 `4+1` 或 `2+2+1`，只触发 2 件与 4 件效果，不设置 5 件效果。

- **雪王·国民常青**：棒打鲜橙、冰鲜柠檬水、珍珠奶茶、茉莉奶绿和新鲜冰淇淋。五款均来自蜜雪集团[《2025 年度报告》](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0423/2026042301901.pdf)公开的年度销量前五，侧重投喂、饱食、馋嘴与温柔照顾；报告未公开五款之间的精确名次，桌宠也不虚构排名。
- **摇摇雪顶**：草莓摇摇奶昔、生打椰椰、雪王雪顶咖啡，以及蓝莓、香芋产品系列。侧重玩耍霜能、摇摇狂欢与组合技；拆到不足四件时，“摇摇狂欢”会立即失效。界面会区分“官方产品”和“官方产品系列”，不表示所有地区当前同时在售。
- **极夜甜品宫**：极夜莓晶露、青提冰翎、苹果雪砂、白桦蜜乳盏和女皇香芋雪冠。这一套是桌宠原创概念，界面明确标注“桌宠原创”，不会冒充蜜雪官方新品。

点击五张槽位卡之一，只会在同一页面展开该槽的三个候选，不另开置顶窗口；也可以一键配齐某个套装。换装使用面板内提示，不增加互动次数、不打断自然作息，也不会弹出外部语言条。

## 二创动作调研

动作方向参考了 Doro 的“平静脸配突然离谱的大轮廓动作”，以及咕咕嘎嘎把吃、睡、护食、闯祸、急哭和求安慰演成短故事的幼崽气质。桌宠没有搬运视频画面或声音，只把这些行为母题重新设计成雪王自己的交互状态。

- [Dororo 桌宠](https://melantech.itch.io/dororo)与[开源实现](https://github.com/MelanTech/Dororo)：不同触摸区域、鼠标跟随与屏幕边缘互动。
- [VPet Simulator](https://github.com/LorisYounger/VPet/blob/main/README_en.md)：大量动画变体、举起、爬墙、舞蹈、食物与主题扩展。

## 文件

- `雪王现代桌宠.ps1`：主程序。
- `启动动态雪王.vbs`：UTF-16LE 静默启动器。
- `assets-source`：二十张统一角色设定的透明主姿态。
- `assets-hq`：实际动画帧和 `manifest.json`。
- `build-snowking-assets.ps1`：从主姿态可重建全部动画帧。
- `build-release.ps1`：生成不含源姿态、测试、构建文件和用户存档的预览压缩包及 SHA-256。
- `VERSION`：当前版本号。
- `COMMERCIALIZATION.md`：收费上架前的权利与工程清单。
- `NOTICE.txt`：随预览包分发的非官方二创说明。
- `tests\test-xuewang-dynamic.ps1`：资源、启动器、作息、互动与持久化自检。
- `INTERACTION-DESIGN.md`：九部位、情境反应、组合动作、四页陪伴屋与珍藏数据规则说明。
